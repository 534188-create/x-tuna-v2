# История изменений

## 2.0.2

- исправлен первый запуск на свежей LucX, когда `subPort` ещё отсутствует;
- TLS-протоколы, включая TrustTunnel, по умолчанию публикуются через общий TCP/443;
- канонический `share_addr` для HTTPS хранится без явного `:443`, а Host endpoint сохраняет порт 443;
- integrity-проверка учитывает штатную нормализацию TrustTunnel до `http2`, не ослабляя контроль клиентов, портов и credentials;
- исправление проверено полным локальным набором и транзакционным repair на чистом Debian 13.

## 2.0.1

- добавлены три самостоятельных варианта установки;
- добавлен быстрый старт для российских узлов через доверенный `gh-proxy.com`;
- installer и `SHA256SUMS` загружаются через один и тот же выбранный источник;
- добавлена переменная `X_TUNA_SUMS_URL` для безопасной проверки зеркала;
- исправлены ссылки документации на отдельный репозиторий `x-tuna-v2`.

## 2.0.0

Первая публикация отдельного репозитория `x-tuna-v2`.

- исходный код и автономный installer отделены от предыдущего репозитория;
- документация собрана в единый русскоязычный набор;
- добавлены TUI, repair после обновления и независимый update-worker;
- добавлены динамическое обнаружение LucX, транзакционный backup/rollback,
  проверка integrity и безопасные release-gates;
- добавлена поддержка clean subscription URL, AnyTLS, AWG, Mieru и фильтрации
  TrustTunnel QUIC;
- исходный Naive Caddyfile остаётся неизменяемым.

Артефакт релиза публикуется отдельно как GitHub Release asset с `SHA256SUMS`.
