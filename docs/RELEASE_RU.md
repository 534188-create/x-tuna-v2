# Выпуск релиза

## Подготовка

1. Проверить текущую ветку и полный diff.
2. Удалить временные файлы и `.pyc`.
3. Выполнить полный тестовый suite.
4. Выполнить secret scan.
5. Проверить Markdown-ссылки и команды.
6. Собрать артефакт дважды.
7. Проверить одинаковый SHA-256.
8. Проверить `sh -n` для автономного файла.

## Артефакты

```text
dist/lucx-post-configure.sh
dist/SHA256SUMS
```

Артефакт должен быть собран из текущих исходников. Устаревший файл нельзя
переименовывать в финальный без повторной сборки.

## Публикация

В GitHub публикуются исходники, тесты, документация, `LICENSE`, `NOTICE` и
инструкции. Скрипт и `SHA256SUMS` публикуются как release assets. Backup,
production manifest, реальные отчёты и credentials не публикуются.

## После публикации

Проверить скачивание через GitHub и доверенное HTTPS-зеркало, checksum и
`x-tuna --help`. Серверную установку выполнять отдельно, после read-only audit.
