# TUI

Главное меню показывает текущие адреса панели и подписки, состояние служб,
сертификата и последнего update job.

В разделе «Краткая справка» описано назначение каждого пункта. В изменяющих
операциях сначала показываются:

- что делает операция;
- какие файлы будут изменены;
- какие поля базы разрешены;
- какие службы будут перезапущены;
- где находится backup;
- что останется неизменным;
- как выполняется rollback.

Длительные операции используют progress или heartbeat. Процент не выдумывается,
если количество шагов неизвестно.
